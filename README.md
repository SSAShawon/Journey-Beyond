## ✈️ About The Project

**Journey Beyond** is a modern and cinematic travel website created to provide an immersive way to explore destinations around the world.

The project combines a visually rich interface with smooth animations, interactive elements, destination information, and an interactive map to create an engaging travel experience.

---

## ✨ Features

- 🌍 Explore beautiful travel destinations
- ✈️ Cinematic travel-focused hero section
- ☁️ Animated visual elements
- 🎬 Smooth and interactive animations
- 🗺️ Interactive real-world destination map
- 📍 Location-based destination exploration
- 🏔️ Destination showcase sections
- 📖 Detailed travel information
- 📱 Fully responsive design
- ⚡ Fast and modern Next.js architecture
- 🎨 Modern UI with Tailwind CSS
- 🧩 Reusable React components

## 🗺️ Interactive Map

Journey Beyond uses **Leaflet** and **React Leaflet** to provide an interactive real-world map experience.

Users can explore destination locations through the map and interact with location-based travel content.

---

## 🎬 Animations & Interactions

The website focuses heavily on creating an immersive travel experience through animations and interactive UI elements.

**GSAP** is used to create smooth animations and enhance the visual experience throughout the website.

The interface is designed to feel dynamic while maintaining usability and readability.
